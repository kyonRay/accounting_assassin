# 首次安装说明

你即将安装的是一个学习 App，跟 App Store 来的程序唯一不一样的是，要做一次"右键打开"，之后就跟普通 App 一模一样。

## 正常安装（3 步）

**步骤 1**：把 `AccountingAssassin.app` 拖到 `Applications` 文件夹里。

**步骤 2**：打开 `Applications` 文件夹，**右键**点 App 图标（笔记本触控板就是两指点击），在弹出的菜单里点 **"打开"**。

**步骤 3**：屏幕中间会再弹一个小窗，里面再点一次 **"打开"**。这一步只需要做一次，之后你双击就再也不会弹这个窗了。

## 如果第 3 步弹窗里没有"打开"按钮（失败兜底 A）

> ⚠️ 如果弹出来的窗只让你点"取消"或"移到废纸篓"，按下面走：

1. 打开"系统设置"（左上角苹果图标 → 系统设置）。
2. 左边栏找到"隐私与安全性"，点进去。
3. 右边页面**滑到最底部**，会看到一行字写着 **"App 已被阻止使用"**，旁边有按钮 **"仍要打开"**。
4. 点 **"仍要打开"**，然后再回去双击 App 图标，会再弹一次确认，再点一次"打开"就好了。

## 如果右键打开仍然被拦（失败兜底 B）

> 💡 提示：从 iCloud 或微信下载的安装包经常会遇到这种情况。复制下面这一行，粘贴到终端里按回车就行：

```
xattr -dr com.apple.quarantine /Applications/AccountingAssassin.app
```

如果你不会打开终端 (Terminal)：按一下 Spotlight 搜索（屏幕右上角放大镜图标，或者按住 `Command` 同时按一下空格键），输入"终端"两个字，按回车，就把终端打开了。然后把上面那一行粘贴进去，再按一次回车。

跑完上面这行之后，回到 `Applications` 文件夹双击 App 就能打开了。

## macOS 大版本升级后又被拦（失败兜底 C）

> ⚠️ 每年秋天 macOS 升完大版本，系统有时会重新拦一次。

升完级之后，再走一次上面的**失败兜底 A**（系统设置 → 隐私与安全性 → 仍要打开）就行了。你之前学到第几章、做过的练习全都还在，不会丢。

## 以上全部失败 —— 找老公

短信发一句"记账杀手 App 打不开"，再带一张当时屏幕的截图。

截屏方法：同时按 `Command + Shift + 3` 三个键，整个屏幕的图片就会自动出现在桌面上，文件名是"屏幕快照 + 日期"。把那张图发过来就行。

## App 装好之后

- 第一次启动会看到欢迎页，跟着上面的提示一步一步走就行。
- 不需要登录账号，不需要填任何个人资料。
- 你的学习进度会自动保存在电脑里，下次打开 App 自动接着上次的地方。
