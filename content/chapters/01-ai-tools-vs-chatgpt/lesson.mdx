# 第 1 章 · AI 工具 ≠ ChatGPT 2.0

## 开场：你过去用 AI "帮自己干活"是什么感觉？

想一想你过去用 ChatGPT 处理发票、报表、对账的典型流程：

1. 打开 Excel，找到要处理的那一段
2. ⌘C 复制
3. 切到 ChatGPT 网页，⌘V 粘进对话框
4. 在前面打一段背景："下面是公司 4 月应付发票明细，帮我按供应商汇总。"
5. 等它生成答案
6. 从答案里挑出要用的几行
7. ⌘C 复制
8. 切回 Excel，⌘V 粘到新位置
9. 手工调整格式
10. （下个月再来一次。）

你做的所有事，其实只有一件：**信息搬运**。你把文件内容搬到 AI 旁边，把 AI 的答案搬回文件。**AI 全程没碰过你的文件。**

---

## 换成 Claude Code，同一件事是这样的

> 你说一句："看下 invoices.csv，按供应商汇总。"
>
> 完。

Claude 自己打开 invoices.csv，自己读懂列名和格式，自己写一段 Python 算出汇总，自己把结果写回新文件或直接展示给你看。**你没有搬运任何东西。**

## 顺带一提："三次答不同"的真正原因

<Callout type="insight" title="它没去算——它在编">
你也许见过 ChatGPT 的"代码解释器"功能——可以上传文件、跑代码。但**默认的聊天模式**下，你粘贴进对话框的文字，它只是在接龙，不是在算。

你问："我有 50 张发票，帮我算总金额。"

- 第一次答：¥12,340
- 第二次答：¥10,890
- 第三次答：¥13,520

这不是 bug，也不是服务器问题。它每次都在根据"发票总金额"这几个字**接龙**，因为它没有你的文件。就算用 ChatGPT 的代码解释器，也要先手动上传文件、等它跑完、再下载结果——每次都要重复这个"上传 → 等 → 下载"循环。

**Claude Code 跑在你电脑里，直接读你硬盘上的文件——所以它给的数字是数字稳定可复算的。** 同一个 prompt 跑两次,Python 的实现细节可能微差(变量名换了、循环写成 comprehension 之类),但跑完聚合出来的金额对得上。**这是会计能信任 AI 的最低门槛:你能用它的输出自己核对一遍。**
</Callout>

## 原理：模型 vs harness（外壳）

<Callout type="tip" title="一句话记住这个区别">
**模型 = 会编故事的大脑**

**模型 + harness = 大脑 + 眼睛 + 手 + 反思**

英文里这一层叫 **harness**（中文可以理解为"AI 的外壳"或"套件"——一个把 LLM 包起来、再加上读文件、跑代码、看结果、终端控制的程序）。中文 AI 圈里没有完全统一的译法，所以这本书里保留英文 **harness** 这个词,免得你以后搜资料时对不上原始概念。

用会计师熟悉的比喻：只有模型，像眼睛被蒙住的同事——嘴里说得头头是道，但看不到你的账本。加上 harness，他把眼罩摘掉，拿到了 Excel 和计算器——这才能真正帮你干活。

**Claude Code、Codex、Cursor 都是 harness**。它们底下可以挂同一个模型(比如 Claude 4.5),但外壳的设计——能调哪些工具、怎么管文件、怎么和你对话——决定了你的体感差别。
</Callout>

<Callout type="insight" title="可追溯、可复算——财务工作的铁律">
ChatGPT 网页版给的数字，来源是"大模型认为这个数字合理"——这不是会计意义上的来源。

Claude Code 给的数字，来源是"它读了你的文件，用这段代码算出来的"——这才是你可以写进工作底稿、可以给审计师看的来源。
</Callout>

## 本章小结

| 维度 | ChatGPT 网页版 | Claude Code |
|---|---|---|
| 谁打开你的文件 | **你**（复制 → 粘贴） | **AI**（它自己） |
| 谁把答案放回文件 | **你**（复制 → 粘贴） | **AI**（它自己写） |
| 答案稳定吗 | 不稳（每次都在编） | 数字稳定可复算（真去算 + 你能照着代码自己跑一遍） |
| 适合什么任务 | 概念解释、文字润色 | 数据处理、文件操作 |

下一章，你将在沙箱环境里运行第一段 Python 代码，让 AI 帮你算出这 6 张发票的总金额。

<Callout type="warn" title="这一章是沙箱演示">
你刚才看到的 "Claude 工具调用回放" 是我们脚本好的剧本 —— 不是真实的 Claude Code 在跑。**为什么这么做?** Part I（Ch 1-4）让你**先看明白 AI 工具是怎么运转的**,不被装环境的麻烦卡住。

</Callout>
