# 第 1 章 · AI 工具 ≠ ChatGPT 2.0

## 开场:你过去用的 AI

<Callout type="insight" title="先想一想">
你之前用 ChatGPT 网页版做过什么?(算账、写汇报、翻译?)它做这些事的时候,**有没有真去打开你的文件**?
</Callout>

大多数人第一次用 AI 做财务工作,都是在 ChatGPT 网页版里输入一段文字,然后等它回答。感觉很智能,回答也有模有样。

但你有没有注意到一件事:如果你连续问三次"我有 50 张发票,帮我算总金额",它给你的数字每次都不一样?

- 第一次:¥12,340
- 第二次:¥10,890
- 第三次:¥13,520

这不是 bug,也不是服务器问题。**它根本没去算——它在编。**

## 原理:模型 vs 装备

你可能会问:为什么 ChatGPT 不能做工具调用?

其实现在的 ChatGPT 也可以——但网页版默认没有开启这些能力。真正的区别在于**装备**,而不是模型本身。

<Callout type="tip" title="一句话记住这个区别">
**模型 = 会编故事的大脑**

**模型 + 装备 = 大脑 + 眼睛 + 手 + 反思**

"装备"是英文 *harness* 的翻译——你不需要记这个英文词,但要知道它代表的是:让 AI 能读文件、跑代码、看结果再反思的那一整套工具和流程。
</Callout>

用一个会计师熟悉的比喻来说:

- **只有模型**:像一个记忆力超强但眼睛被蒙着的同事——他能说出很多会计术语,但看不到你的账本。
- **模型 + 装备**:像同一个同事把眼罩摘掉,拿到了你的 Excel 文件,还有计算器——他现在真的能帮你干活了。

---

## 为什么对会计师特别重要

<Callout type="insight" title="可追溯、可复算">
财务工作有一条铁律:**每一个数字都必须能追溯来源**。

ChatGPT 网页版给的数字,来源是"大模型认为这个数字合理"——这不是会计意义上的来源。

Claude Code 给的数字,来源是"它读了你的文件,用这段 Python 代码算出来的"——这才是你可以写进工作底稿、可以给审计师看的来源。
</Callout>

用 AI 工具做账,不是为了"快"——是为了**可追溯、可复算、不出错**。

工具调用型 AI 天然符合这个要求:它的每一步都留有记录,你可以复查每一个工具调用、每一行代码、每一个中间结果。

| | ChatGPT 网页版 | Claude Code |
|---|---|---|
