## AI 写出来的脚本长这样

这就是 AI 一次性写出的批量处理脚本 —— 简洁、地道,17 行:

```python
import csv
import glob
from collections import defaultdict

totals = defaultdict(float)

# 自动找到当前目录下所有 invoices-2026-*.csv 文件
for path in sorted(glob.glob("invoices-2026-*.csv")):
    with open(path) as f:
        for row in csv.DictReader(f):
            totals[row["category"]] += float(row["amount"])

# 按类目名称排序后打印
for cat in sorted(totals):
    print(f"{cat}: ¥{totals[cat]:.2f}")
```

**你不需要理解每一行** —— 只需要看懂它在做什么:

1. `glob.glob("invoices-2026-*.csv")` —— 自动找到所有 12 个月的文件
2. `csv.DictReader` —— 按列名读每一行
3. `totals[category] += amount` —— 把金额累加到对应类目
4. 最后打印每个类目的总金额
