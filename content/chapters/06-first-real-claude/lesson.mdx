# 第 6 章 · 第一次与真实 Claude Code 对话

## 1. 验证安装——claude --version

在开始对话之前，先确认 Claude Code 已经正确安装在你的电脑上。打开终端，运行下面的命令：

<RealStep
  id="claude-version-checked"
  expectsCli="Claude"
  command="claude --version"
>
  在终端里运行上面的命令。

  你应该看到类似下面的输出（只有一行）：
  ```
  2.0.5 (Claude Code)
  ```
  版本号（前面的 `2.0.5`）会不一样，括号里固定是 `(Claude Code)`。

  看到这一行就说明安装成功了。
</RealStep>

<Callout type="warn" title="看到 command not found？">
如果终端显示 `command not found: claude`，说明 Claude Code 还没安装，或者 Shell 还不知道去哪里找它。

按顺序尝试：
1. 关闭当前终端窗口，重新打开一个新窗口
2. 运行 `source ~/.zprofile` 或 `source ~/.zshrc`
3. **仍然 `command not found`**：跑 `which claude` 看看 PATH 里能不能搜到。如果输出是空的 → 说明装的时候有问题，回到第 5 章重新装一遍 Claude Code。
4. **装是装上了但启动时卡住 / 报错**：跑 `claude doctor`（Claude Code 自带的诊断子命令），它会告诉你是哪一步出错（PATH、权限、配置、网络都会检查）。
</Callout>

## 2. 第一次对话

<Callout type="tip" title="~/accounting-learner/ 是什么？">
进入真实环境时，记账杀手 App 已经在你的电脑上创建了 `~/accounting-learner/` 目录 —— 这是你接下来所有练习的工作区。
</Callout>

你的工作目录在 `~/accounting-learner/`。Claude Code 对话时，它会把当前目录当作"工作间"，读写文件都在这里发生。

<Callout type="warn" title="先确认你有 Claude Code 的使用权限（重要）">
Claude Code **需要付费订阅或 API 余额**才能在自己的电脑上跑起来。注册 Anthropic 账号本身是免费的，但用 `claude` 这个命令发消息会扣费/扣额度。常见的方式有两种：

- **Claude Pro / Max 订阅**（个人，每月固定费用）—— 适合每天用 Claude Code 工作的人，按月付费，不按消息计费
- **Anthropic Console API 余额**（充值，按使用量扣费）—— 适合偶尔用一下，或者想精确控制每月开销

登录之后，Claude Code 会自动用你账号对应的那种付费方式。

如果你第一次发消息时看到类似 `subscription required`、`no active subscription`、`insufficient credit` 的英文报错，就是这一步还没搞定 —— 去 [https://www.anthropic.com/pricing](https://www.anthropic.com/pricing) 选一种方案开通后再回来。

> 本应用不会替你付费，也看不到你的账单。这是你和 Anthropic 之间的事情。
</Callout>

<Callout type="warn" title="如果登录卡住了（常见兜底）">
第一次登录是这一章最容易卡住的环节。按你的情况对号入座：

- **浏览器没自动打开**：回到终端，找一行类似 `https://claude.ai/oauth/...` 的链接，手动复制到浏览器里打开
- **登录后浏览器停在空白页 / 一直转圈**：关掉浏览器，回到终端 —— 通常已经显示 `Logged in` 之类的提示，可以继续
- **公司网络/代理拦截了 OAuth**（国内最常见）：试着开手机热点或换网络；实在不行就走 API 余额方式，把 `ANTHROPIC_API_KEY` 设到环境变量里（具体怎么开通见上面那个 Callout 里的链接）
- **终端是远程 SSH / WSL / Codespaces**：Claude Code 会打印一个数字码，你在**本地电脑的浏览器**完成登录后，把那个码回填到终端里就行
</Callout>

<RealStep
  id="first-conversation"
  command="cd ~/accounting-learner && claude"
>
  在终端里运行上面的命令：先切换到工作目录，然后启动 Claude Code。

  **第一次运行会有几件事发生：**

  1. 如果你还没登录过 Anthropic，Claude Code 会在浏览器里打开一个认证页面——在那里用 Anthropic 账号登录（或新建账号）。账号本身是免费的，但要让 `claude` 真的能发消息，需要前面提到的订阅或 API 余额。
  2. 登录完成后回到终端，过几秒你会看到 Claude Code 的欢迎界面：终端最下方是一个空白的输入框，光标在闪；上方会有一两行英文提示，告诉你可以输入 `/help` 查看可用命令。
  3. 直接在输入框里输入你的第一句话。我们用一个会计场景做开场——让 Claude 读你工作目录里的 README.md：
     ```
     读一下当前目录的 README.md，用一句话告诉我这个目录是干嘛的
     ```
     （Ch 5 自动创建工作目录时已经放了一份 README.md 在 `~/accounting-learner/` 里，所以 Claude 一定能读到。）
  4. 按回车，等 Claude 回应

  Claude 会用 `Read` 工具打开 README.md，然后用中文给你一句话总结。这就是第一次工具调用了——你看着 Claude 真的去读了一个真实文件，而不是凭空回答。

  看到 Claude 的回应之后，按 **`Ctrl+C` 两次**退出 Claude Code（也可以输入 `/quit` 然后回车），回到普通的终端提示符之后，再点「我跑完了」。
</RealStep>

<Callout type="tip" title="Claude 在对话里能做什么？">
在 `~/accounting-learner/` 目录下，Claude Code 可以：

- 读取这个目录里的任何文件（发票、CSV、Python 脚本）
- 写入新文件或修改现有文件
- 跑 Python 脚本并显示输出
- 使用工具（你会在工作日志里看到 `🔧 Read`、`🔧 Write`、`🔧 Bash` 等）
</Callout>

<Callout type="warn" title="权限确认框：看清路径再批准">
**Claude 每次想读或写文件之前，都会弹一个权限确认框，告诉你它想动哪个文件 / 哪个目录。看清路径再决定要不要批准。**

Claude Code 不是硬沙箱——你点 Allow，它就能访问；技术上它可以请求你电脑上的任何路径，不只是 `~/accounting-learner/`。

**不要无脑点 Allow**：

- 如果路径就在你当前工作目录里（比如 `~/accounting-learner/invoices/2026-01.csv`），一般可以批准
- 如果路径不在你工作目录里（比如莫名要读 `~/.ssh/`、`~/Library/Keychains/`、`/etc/passwd`），**拒绝**，并问 Claude 一句"为什么需要这个文件？" —— 它必须能讲清理由，否则别给
- 弹窗里通常有「这次允许」/「永久允许」两种选项，刚学的时候先选「这次允许」，养成每次看一眼路径的习惯
</Callout>

<Callout type="warn" title="什么不能让 Claude 看（财务数据隐私底线）">
Claude Code 每次对话——包括你打字的内容、它读到的文件片段——都会发送到 Anthropic 的服务器才能得到回应。所以下面这些**真实的、可以直接识别个人 / 公司的数据**，不要原样贴进对话框，也不要让 Claude 读包含它们的真实文件：

- 客户姓名 / 联系方式 / 身份证号
- 银行卡号 / 完整账号 / 网银密码 / 支付密码
- 供应商真实税号 / 真实金额（脱敏处理后再发，比如 `XXX 公司，金额 XX 万`）
- 工资条上的具体姓名 + 金额组合

**一句话总结：你能想到给同事看时要遮挡的信息，Claude 也别看。**

**测试 / 学习用的脱敏假数据没问题**——本教材后面所有的发票、客户、金额都是编出来的。Ch 7 之后我们会专门演示：怎么把真实文件先脱敏（把姓名换成 `客户A`、金额抹零）再喂给 Claude。
</Callout>

## 3. 认证与 ~/.claude/ 配置目录

第一次成功登录之后，Claude Code 会在你的主目录下创建一个 `~/.claude/` 目录。这个目录里存放的是：

- 你的认证凭证（登录状态）
- Claude Code 的配置文件
- 会话历史记录

我们可以来确认一下这个目录确实存在：

<RealStep
  id="claude-config-verified"
  command="ls ~/.claude/"
>
  在终端里运行上面的命令，查看 `~/.claude/` 目录下有哪些文件。

  你应该能看到 `settings.json` 文件，可能还有 `projects/`、`sessions/` 等其他文件和文件夹 —— 这些都是正常的。

  只要目录存在、里面有东西，就说明认证成功了。
</RealStep>

<Callout type="insight" title="~/.claude/ 存什么？">
`~/.claude/` 是 Claude Code 的个人配置根目录，类似 `~/.ssh/` 之于 SSH。

**它不包含你的数据**（发票、账目等都在 `~/accounting-learner/`），只包含配置和凭证。

本应用永远不会读取 `~/.claude/` 里的内容——那是你和 Claude Code 之间的私有数据。这里让你确认它存在，纯粹是为了证明认证流程跑通了。
</Callout>

| 你做了什么 | 意义 |
|---|---|
| `claude --version` | 确认 CLI 工具可用 |

| 确认 `~/.claude/` 存在 | 认证已完成，以后打开 Claude 不会再要求重新登录 |
