# 第 10 章 · Hooks 与 MCP：让 Claude 接入你的工具链

## 1. 一张图：Skills / Hooks / MCP 三件事

<RealStep
  id="three-mechanisms-understood"
  command=""
>
  读完这一节，理解三种机制各自的触发方式和适用场景，然后点「我跑完了」。
</RealStep>

Ch 9 你学了 Skill——给 Claude 写一份任务说明书，让它更聪明地处理重复任务。  
但 Claude Code 还有两种更深的扩展方式：**Hook** 和 **MCP**。

| 工具 | 形态 | 触发 | 何时用 |
|---|---|---|---|
| **Skill** | `~/.claude/skills/<name>/SKILL.md`（Markdown 说明书） | Claude 看到匹配的请求时自动调用 | 重复的多步工作流（你描述给同事的那种任务） |
| **Hook** | `.claude/settings.local.json` 里配置的 shell 命令 | Claude Code 做特定操作时自动跑（比如 PostToolUse） | 每次某件事发生时都要做的机械动作（写日志、检查格式） |
| **MCP** | 一个长期运行的外部进程（binary 或 npx 进程） | Claude 启动会话时连接，以工具形式调用 | 让 Claude 具备它原本没有的能力（SQL 查询、Slack、Linear...） |

<Callout type="insight" title="三句话记住它们">
  **Skill 是说明书**——告诉 Claude 「碰到这类请求，按这个流程做」。  
  **Hook 是触发器**——告诉 Claude Code「每次做完某个操作，跑这段 shell」。  
  **MCP 是新工具**——把一个外部能力（比如直接查 SQL）挂到 Claude 的工具箱里。
</Callout>

## 2. 写第一个 Hook：编辑后自动追加日志

<RealStep
  id="hook-installed"
  command=""
>
  按下面的步骤，在 `.claude/settings.local.json` 里加一个 PostToolUse hook。完成后点「我跑完了」。
</RealStep>

### 为什么先从日志 hook 入门？

最安全的第一个 hook 是**只追加写文件**的 hook——它不会修改代码，不会发网络请求，出错了也不影响你的工作。

### 配置步骤

**第一步**：在项目根目录创建（或打开）`.claude/settings.local.json`。  
这个文件是**项目级配置**，不会影响其他项目的 Claude Code 设置。

```bash
# 如果 .claude/ 目录还不存在：
mkdir -p ~/accounting-learner/.claude
```

**第二步**：把下面这段 JSON 写入 `~/accounting-learner/.claude/settings.local.json`：

<Callout type="warn">
  如果 `.claude/settings.local.json` 已经存在其他配置（之前的章节可能写过），**只把 `"hooks": { ... }` 这部分合并进去**，不要直接覆盖整个文件。
</Callout>

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit",
        "hooks": [
          {
            "type": "command",
            "command": "echo \"[$(date '+%Y-%m-%d %H:%M:%S')] Edit triggered\" >> ~/accounting-learner/.edits.log"
          }
        ]
      }
    ]
  }
}
```

**字段说明**：

| 字段 | 含义 |
|---|---|
| `"PostToolUse"` | 事件名：Claude Code 调用完某个工具之后触发 |
| `"matcher": "Edit"` | 只在用了 `Edit` 工具之后触发（其他工具不触发） |
| `"type": "command"` | hook 的类型是运行 shell 命令 |
| `"command"` | 要跑的 shell 命令：把时间戳追加写入日志文件 |

<Callout type="tip" title="为什么用 PostToolUse 而不是 PostEdit？">
  Claude Code 的 hook 事件系统版本在持续演进。当前（2026-05）正式支持的编辑后事件是
  `PostToolUse`，用 `matcher` 指定 `"Edit"` 来筛选编辑操作。你可以在
  `~/.claude/settings.json` 里看到你已有的 hook 用的就是这个格式。
</Callout>

## 3. 让 Hook 跑起来

<RealStep
  id="hook-verified"
  command="cat ~/accounting-learner/.edits.log"
>
  让 Claude 对项目里任意一个文件做一次小修改，然后用上面的命令检查日志是否出现了新的时间戳记录。确认后点「我跑完了」。
</RealStep>

### 验证步骤

1. 确保 Claude Code 是在 `~/accounting-learner/` 目录下启动的（这样它才能读到 `.claude/settings.local.json`）：

   ```bash
   cd ~/accounting-learner
   claude
   ```

2. 在 Claude 对话里随便让它改一个文件，比如：

   ```
   帮我在 README.md 里加一行：「本月发票整理完成」
   ```

3. 对话结束后，在另一个终端里检查日志：

   ```bash
   cat ~/accounting-learner/.edits.log
   # 应该出现类似：
   # [2026-05-21 10:23:45] Edit triggered
   ```

<Callout type="tip" title="如果 hook 没触发">
  检查以下几点：
  1. **JSON 语法**：用 `python3 -c "import json; json.load(open('.claude/settings.local.json'))"` 验证 JSON 格式
  2. **启动目录**：Claude Code 必须在 `~/accounting-learner/` 目录下启动，才能读到项目级配置
  3. **日志目录权限**：确保 `~/accounting-learner/` 目录存在且可写
</Callout>

## 4. 装 SQLite MCP

<RealStep
  id="sqlite-mcp-installed"
  command="claude mcp list"
>
  按下面步骤安装 SQLite MCP 服务器，然后运行上面的命令确认它出现在列表里，点「我跑完了」。
</RealStep>

MCP（Model Context Protocol）是 Anthropic 制定的开放协议，让 Claude 能调用任意外部工具——只要那个工具实现了 MCP 接口。SQLite MCP 是最简单的入门示例：它让 Claude 直接查询 SQLite 数据库文件。

### 安装步骤

**前提**：需要 `uv`（Python 包管理器）。如果还没装：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

也可以用 Homebrew：`brew install uv`（Ch 5 已经装好了）

**安装 SQLite MCP 服务器**：

用 `claude mcp add` 命令注册 MCP 服务器——这是 Anthropic 官方推荐的方式，比手工改配置文件安全得多（配置文件名和位置在不同版本里变过几次，CLI 永远写到正确位置）：

```bash
claude mcp add sqlite-db -s user -- uvx mcp-server-sqlite --db-path "$HOME/accounting-learner/accounting.db"
```

**命令拆解**（看着长，其实结构很简单）：

| 部分 | 含义 |
|---|---|
| `claude mcp add` | 添加一个 MCP 服务器 |
| `sqlite-db` | 你给这个服务器起的名字（自定义） |
| `-s user` | 作用域：`user` 表示「所有项目都能用」；不写默认是 `local`（只当前目录） |
| `--` | 分隔符，告诉 CLI「后面这些是要启动的子进程命令和参数，不是 `claude` 自己的选项」 |
| `uvx mcp-server-sqlite` | 子进程命令——用 `uvx` 临时下载并运行 `mcp-server-sqlite` 包 |
| `--db-path "$HOME/..."` | 传给 `mcp-server-sqlite` 的参数：指定数据库文件位置 |

<Callout type="tip" title="为什么用 $HOME 不用 /Users/你的用户名？">
  `$HOME` 是 macOS 和 Linux 自带的环境变量，会自动展开成你当前用户的 home 目录（比如 `/Users/zhangsan`）。**你不用替换它，直接复制粘贴上面的命令就行**。如果你写 `/Users/你的用户名` 那种字面量，shell 会把它当成真的目录名找不到。
</Callout>

**验证安装**：

```bash
claude mcp list
# 应该看到类似：
# sqlite-db: uvx mcp-server-sqlite --db-path /Users/你的用户名/accounting-learner/accounting.db - ✓ Connected
```

如果状态不是 `✓ Connected`：

- 数据库文件还不存在？这是下一节的事，先建好 `accounting.db` 再回头看（也可以先 `touch ~/accounting-learner/accounting.db` 让文件占位）
- 看不到 `sqlite-db` 这一行？可能 `claude mcp add` 报错了——往回看终端是否有红色错误提示，或者重跑一次 `claude mcp add ...`
- 想撤销重来：`claude mcp remove sqlite-db -s user`

<Callout type="tip" title="uvx 是什么？">
  `uvx` 是 `uv` 提供的命令，功能类似 `npx`：它临时下载并运行一个 Python 包，不需要手动
  `pip install`。`mcp-server-sqlite` 就是 Anthropic 官方维护的 SQLite MCP 服务器包。
</Callout>

<Callout type="insight" title="配置文件在哪？（好奇的同学可以看）">
  `claude mcp add` 会把你的 MCP 配置写到 `~/.claude.json`（user 作用域）或当前项目根目录的 `.mcp.json`（project 作用域）。**你不需要手工编辑这些文件**——CLI 永远知道正确位置和格式，手工改容易写错。需要修改时，用 `claude mcp remove` + `claude mcp add` 重新注册。
</Callout>

## 5. 让 Claude 用 MCP 查 SQL

<RealStep
  id="mcp-query-tried"
  command="claude"
>
  按下面步骤创建示例数据库，然后用自然语言请求 Claude 查询，确认它通过 MCP 工具返回了结果。完成后点「我跑完了」。
</RealStep>

### 准备一个示例数据库

先创建一个有发票数据的 SQLite 数据库：

```bash
cd ~/accounting-learner
sqlite3 accounting.db << 'SQL'
CREATE TABLE IF NOT EXISTS invoices (
  id INTEGER PRIMARY KEY,
  date TEXT,
  vendor TEXT,
  amount REAL,
  category TEXT
);
INSERT INTO invoices VALUES
  (1, '2026-05-01', '顺丰速运', 280.00, '快递'),
  (2, '2026-05-03', '盒马鲜生', 156.50, '餐饮'),
  (3, '2026-05-08', '顺丰速运', 95.00, '快递'),
  (4, '2026-05-12', '滴滴出行', 42.00, '交通'),
  (5, '2026-05-15', '盒马鲜生', 230.00, '餐饮'),
  (6, '2026-05-20', '京东物流', 180.00, '快递');
SQL
echo "数据库创建完成"
```

### 开 Claude 会话，用自然语言查询

```bash
cd ~/accounting-learner
claude
```

然后对 Claude 说：

```
查一下本月发票按类目的总金额，从高到低排列
```

正常情况下，Claude 会调用 SQLite MCP 的 `query` 工具，运行类似这样的 SQL：

```sql
SELECT category, SUM(amount) AS total
FROM invoices
WHERE date LIKE '2026-05-%'
GROUP BY category
ORDER BY total DESC;
```

并返回结果表格。

<Callout type="warn" title="MCP 是 Claude 调用的工具，不是任意 SQL 执行器">
  MCP 让 Claude 代表你查询数据库——但你的请求是否合理，**你自己把关**。  
  不要让 Claude 通过 MCP 执行 `DROP TABLE`、`DELETE` 这类破坏性操作。  
  教学场景里，只用 `SELECT` 查询。
</Callout>

## 6. 三件事的对比：何时选哪个

学到这里，我们完整经历了 Claude Code 三种扩展机制：

| 你想做的事 | 选哪个 | 原因 |
|---|---|---|
| 让 Claude 按固定流程整理发票（月月如此） | Skill | 说明书，让 Claude 更聪明地理解你的重复任务 |
| 每次 Claude 编辑代码后自动跑 lint / 写日志 | Hook | 触发器，机械地在某个操作后执行 shell 命令 |
| 让 Claude 直接查 SQLite / 发 Slack 消息 | MCP | 新工具，给 Claude 挂载它原本没有的能力 |
| 问 Claude「什么是应收账款」 | 直接问 | 一次性问答，三种机制都用不上 |

**判断流程**：

```
这件事是重复的多步工作流 → Skill
每次某个操作触发就要自动运行 → Hook
Claude 需要调用它本身不会的工具 → MCP
一次性、简单的请求 → 直接说
```
